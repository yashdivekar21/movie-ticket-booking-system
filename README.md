# Movie Ticket Booking System

A beginner-friendly Movie Ticket Booking System developed using Python.

## About the Project

This is a simple console-based application that allows users to view available movies, select seats, book tickets, and calculate the total ticket price.

## Features

- View available movies and ticket prices
- Select a movie
- View available seats
- Book multiple seats
- Calculate the total ticket price
- Prevent duplicate seat bookings
- Display booking confirmation

## Technologies Used

- Python 3

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

   `python main.py`
